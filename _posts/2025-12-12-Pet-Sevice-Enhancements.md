## Enhanced Versions
### Stage One: [Software Design](https://github.com/foxkicks/Cplusplus-Program/blob/main/CS-499/PetService%20(Software%20Design).zip)
#### Briefly describe the artifact. What is it? When was it created?
The original artifact was created as an assignment explaining the interactions between classes and subclasses. It was created for IT-145 in 2023 at the beginning of my coding journey. We were tasked to create a parent and child class. The parent class, named “Pet” was meant to set the baseline for all other pet species. A “Dog” class was created as a child, or subclass of the Pet class. This artifact was meant to teach inheritance from parent classes and definitions of child classes. If this artifact were continued as it was planned, another subclass would have been created for each species. It would eventually end up with a console program meant to check pets in and out.
#### Justify the inclusion of the artifact in your ePortfolio. Why did you select this item? What specific components of the artifact showcase your skills and abilities in software development? How was the artifact improved?
This artifact’s inclusion in my ePortfolio is more to show how much I’ve learned in the last few years. This item is incomplete and from a time when I didn’t understand classes in programming much. My skills are being shown by the improvements I am making to it. I am making a program that follows the original intent of what the full program would have been: a means to check animals in and out of a boarding and grooming center. In doing so, I will show the skills I’ve picked up along my journey so far.
#### Reflect on the process of enhancing and modifying the artifact. What did you learn as you were creating it and improving it? What challenges did you face?
Modifying the artifact in this case meant starting from scratch. What was two class files is now a WinForms project. What was once a lesson on classes and subclasses is now a controlled vector of one class. For the purposes of the enhancements, the subclasses are not needed. This new program will include all functionality of what the original program was meant to be.
The original file only contains the two poorly coded classes, so a lot of work had to be done. In Visual Studio, I used the designer to create radio buttons to separate the check-in and check-out controls, panels for the controls to sit in, and the controls themselves. This makes it easier to hide and show the entire set of controls for each purpose. I learned about panels during this enhancement, assuming that it would be there after using canvas panels for widgets in Unreal Engine 5 for my game development courses. After defining most of the logic, I realized that I had left some vital parts out needed for the check-out system. For time reasons, some variables are hard coded. The inclusion of a weight input, grooming checkbox, and a days selector for the checkout price calculations in the interface will be implemented alongside the second enhancement.


### Stage Two: [Data Structures & Algorithms](https://github.com/foxkicks/Cplusplus-Program/blob/main/CS-499/PetService%20(Data%20Structures%20and%20Algoritms).zip)
#### Briefly describe the artifact. What is it? When was it created?
As stated in the first enhancement, this original artifact is two incomplete and poorly coded Java classes. My understanding of programming at the time was very limited. This was a module assignment for IT-145, where we were tasked to create a class and subclass with getters and setters. It was created in 2023. The parent class is called “Pet”, and the child class is called “Dog”, and the assignment was meant to give experience in working with classes before working on a similar but different program.
#### Justify the inclusion of the artifact in your ePortfolio. Why did you select this item? What specific components of the artifact showcase your skills and abilities in software development? How was the artifact improved?
The artifact is included in my ePortfolio because it is a good way to show my own growth as a programmer. Selecting an item so incomplete and wrong allows me to prove myself more capable than I was when I first wrote the lines for that assignment. The enhanced artifact makes use of a vector that stores objects of the Pet class. The vector can be added to and removed from. The check-in system has algorithms for ensuring that the spaces are available as well as for making sure every field is correctly filled. The check-out system has an algorithm for calculating fees taking days past, grooming fees, and animal weight into account.
#### Reflect on the process of enhancing and modifying the artifact. What did you learn as you were creating it and improving it? What challenges did you face?
I met the course outcomes that I planned to meet in Module One, though I didn’t end up using a hash map for the data structure. The planned design and algorithms are in place. I will complete every outcome by the end of the course, if I haven’t already.
When modifying the artifact to enhance it, I learned that I needed to redesign the input areas to fit the new fields in. I needed to add a checkbox to get a grooming boolean as well as another text field for weight input that declines non-numerical inputs. It turned out less difficult to implement than I expected.

### Stage Three: [Databases](https://github.com/foxkicks/Cplusplus-Program/blob/main/CS-499/PetService%20(Final%20-%20Databases).zip)
#### Briefly describe the artifact. What is it? When was it created?
The original artifact was created in 2023 as an assignment for one of my first coding classes, IT-145. It was meant to introduce us to the concept of subclasses and inherited functions. It consists of a parent Pet class and a child Dog class. I did not quite understand the concept at the time, nor did I understand the concept of getters and setters so well.
#### Justify the inclusion of the artifact in your ePortfolio. Why did you select this item? What specific components of the artifact showcase your skills and abilities in software development? How was the artifact improved?
I included this artifact to show my improvement over the course of my Computer Science journey. My code went from incorrect irreverence to functional and readable. The first improvement was software design, where I started the program from scratch and created a GUI for it. The second improvement was for data structures and algorithms, where I stored the data in vectors and implemented an algorithm for the buttons to perform. This improvement is adding a database, through SQLite. The program now can add and remove elements from a database that is part of the filesystem.
#### Reflect on the process of enhancing and modifying the artifact. What did you learn as you were creating it and improving it? What challenges did you face?
Modifying this artifact taught me something new about SQLite in C#. There are safer ways to do the tasks I had originally planned. I wanted to brute force many of the executions with a simple command. I’ve learned that it’s better to use coded parameters rather than a single command to avoid issues with apostrophes. The biggest challenge I faced was at the very beginning, having to figure out with NuGet package to download for the best compatibility.
