## SoapFox

Link: https://soapfox.onrender.com/

### Gameplay:
- Each player submits a question
- Each player receives two questions and provides their best answers.
- Players vote on which answer is better.
- Repeat the voting phase until all questions are done.
- The winner is the player with the highest answer score.
### Known Issues:
- No disconnect logic. Players will not be removed from a room if they leave, and cannot reconnect. TEMPORARY FIX: Make a new lobby if a player leaves.
- Game is allowed to be played with only two players. It's staying like this during early phases for quicker testing.
- Game will sometimes take time to load up. This is because I'm running it on a free Render server that shuts off during inactivity.
